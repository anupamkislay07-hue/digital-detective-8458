# Mission 02 – Terminal

## Tasks

- [ ] **Task 2.1:** Practice basic terminal commands (`pwd`, `ls`, `ls -l`, `cd`, `mkdir`, `touch`, `cp`, `mv`, `cat`) and record your observations.
- [ ] **Task 2.2:** Practice safe file changes (`>` vs `>>`, `cp` vs `mv`) and answer the questions in your own words.
- [ ] **Task 2.3:** Explore flags (`ls -lah`) and pipes (`|`, `head`, `tail`).
- [ ] **Task 2.4:** Inspect your package manager (e.g., `brew --version`, `which brew`, `brew list`).
- [ ] **Reflection:** Summarize what you learned and difficulties faced.
