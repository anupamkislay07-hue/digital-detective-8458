## About This Project

This repository contains my work for the Digital Detective Diwali Independent Learning Assignment. It is organised into nine missions, numbered 00 to 08, covering computer fundamentals, terminal commands, operating systems, programming, number systems and text encoding, Git and GitHub, and networking.

Each mission has its own folder and README documenting the tasks, what I learned, difficulties, evidence and commit details. The missions were documented and committed separately so the work can be reviewed in order.

## Running the Number Converter

The project includes a Python program that converts a decimal number into binary and hexadecimal representations. From the repository folder, run:

```bash
python3 mission-05-numbers-data/number_converter.py
```

Enter a positive decimal number when prompted. The program displays its decimal, binary and hexadecimal representations.

## My Learning

1. **A computer system follows a flow.** Tracing an activity through input, processing, output and storage helped me connect the parts of a computer to what I do with it.
2. **The Terminal gives direct access to file operations.** Practising commands, flags and pipes helped me understand how to inspect and manage project files.
3. **Git records changes in steps.** Separate commits and the `update-about` branch made it easier to review how work changed before it reached `main`.
