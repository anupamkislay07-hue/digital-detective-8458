# Mission 01 – Computer Basics

## 1. Mission Objective

Understand how a computer system follows the IPOS (Input, Processing, Output, Storage) cycle, distinguish between hardware and software categories, and recognize computer-based systems in everyday life.

---

## 2. Task 1.1 – Trace One Activity Using IPOS

**Activity chosen:** Recording and sending a voice note on WhatsApp using a smartphone.

| Stage | What happens | Hardware / Component |
|---|---|---|
| **Input** | Hold down the mic icon and speak; sound waves enter the bottom microphone and convert into raw digital audio while the touchscreen detects the touch-and-hold gesture. | Microphone, Touchscreen |
| **Processing** | The phone filters background fan noise, balances/normalizes volume levels, and compresses the raw audio into a smaller, sendable audio format. | Mobile SoC (CPU / DSP) and RAM |
| **Output** | Live sound waveforms and a running timer appear on the display while recording; tapping play outputs the recorded audio as sound. | Display (Screen), Speaker |
| **Storage** | Releasing the mic button saves the audio clip to the phone's internal storage and uploads a copy to the cloud for chat history playback. | Internal Flash Storage (and Cloud Storage) |

### Summary

Recording a voice note shows all four IPOS stages working together in real time: capturing physical sound and touch as digital input, processing and compressing that data in memory, giving visual and audio feedback as output, and persisting the clip in internal/cloud storage.

## 3. Task 1.2 – Identify Hardware and Software

| Item / Software | Hardware or Software? | Category / Type | Purpose |
|---|---|---|---|
| **Apple Silicon chip (SoC)** | Hardware | Processor / Graphics | Runs apps, handles graphics, and keeps power usage efficient for battery life. |
| **Unified Memory (RAM)** | Hardware | Memory | Holds active tabs and running apps so multitasking stays smooth without lag. |
| **SSD** | Hardware | Permanent Storage | Stores files and apps while keeping boot and app launch times fast. |
| **Trackpad** | Hardware | Input Device | Enables scrolling, clicking, and multi-finger navigation gestures. |
| **Finder** | Software | System / File Manager | Browses folders, previews files, and transfers files via AirDrop. |
| **Spotlight (`Cmd + Space`)** | Software | Utility | Quickly launches apps, searches files, and evaluates quick calculations. |
| **Google Chrome** | Software | Application | Browses the web, runs web apps, opens docs, and supports research. |
| **Rectangle** | Software | Utility | Snaps and tiles application windows side-by-side using keyboard shortcuts. |

## 4. Task 1.3 – Computer Systems Around You

| System | Main Purpose | One Input | One Output |
|---|---|---|---|
| **Smartwatch** | Tracks daily steps, heart rate, and workouts while delivering quick notifications on the wrist. | Touch screen / heart-rate sensor | Wrist vibration or small screen alert |
| **Smart TV** | Streams shows, movies, and YouTube videos onto a living-room display. | Remote control button press (or voice command) | Video and audio on screen and speakers |
| **Wireless Earbuds** | Plays music, podcasts, and call audio wirelessly with on-the-go playback/call controls. | Touch tap on the earbud stem | Audio played directly into the ears |

## 5. Reflection

Breaking everyday tech down into input, processing, output, and storage made me realize how many hidden steps happen in a split second behind simple actions. The trickiest part was separating processing from output—like distinguishing between audio cleanup happening inside the phone versus the actual playback I hear.
